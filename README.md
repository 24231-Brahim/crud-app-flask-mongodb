# crud-app-flask-mongodb
CRUD web application built with Flask and MongoDB with a modern CSS interface


## Technologies Used

- Python
- Flask
- MongoDB
- PyMongo
- HTML
- CSS
- UUID for custom ID management

---

## Installation

1. Clone the repository: git clone https://github.com/24231-Brahim/flask-mongodb-user-management.git
2. Install dependencies: pip install flask pymongo
3. Make sure MongoDB is running locally: mongod
4. Run the application: app.py


Open in your browser: http://127.0.0.1:5000



---

## Features

- Add new users
- View all users
- Edit user information
- Delete users
- Modern responsive CSS interface
- Custom UUID-based ID system (no ObjectId dependency)
